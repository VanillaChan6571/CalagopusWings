## Unit baseline

CatWings `go test ./...` passed across all packages at the pinned revision.

Calagopus declares Rust 1.99.0. The production host's default Rust is 1.96.1
and the host does not have CMake, so no global toolchain default or OS packages
were changed. Rust 1.99.0 was installed as an explicit side-by-side toolchain,
and the locked workspace suite was run in the isolated build container provided
by `comparison/run-calagopus-container.sh`.

Calagopus result:

- 879 passed;
- 8 failed;
- 32 ignored; and
- 0 PBS client tests.

All eight failures were the inotify harness failing to register watches inside
the build container. The already-built test binary was then run directly on the
host filesystem with only those eight cases selected; all eight passed in 0.08
seconds. Across the appropriate environments, all 887 executed cases passed.
The remaining 32 root- or Docker-dependent ignored tests still require a
disposable VM and must not be enabled against this production host.

## Feature-source signals

Calagopus has dedicated implementation areas for file revisions, trash,
collaboration, SQLite queries, file history, ZIP, and 7-Zip. CatWings contains
ZIP implementation and tests but no corresponding source signals for the first
five features at the pinned revision.

This establishes that Calagopus has a materially broader engine surface. It
does **not** establish API compatibility with NekoHosting, production safety,
lower resource usage, or better game-server performance. Those questions need
the disposable-node contract, workload, soak, and fault phases described in
`comparison/README.md`.

## Current conclusion

Calagopus is strong enough to justify a real canary comparison. It is not yet a
replacement recommendation. CatWings currently has the lower integration risk
because it is the deployed fork and its local suite passes. Calagopus has the
larger built-in feature set and much deeper unit coverage, but its API behavior,
resource profile, and operational recovery still need identical black-box
tests against CatWings.
